  MORNING (Start Development):
  1. Double-click: start_all.bat
  2. Wait for Chrome to open
  3. Start coding!

  DURING DAY (If something breaks):
  1. Double-click: check_services.bat
  2. See what's wrong
  3. Restart that service

  EVENING (End Development):
  1. Double-click: stop_all.bat
  2. Close terminal windows
  3. Done!

 🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Problem: "MySQL connection failed"
  Solution:
    1. Press Windows + R
    2. Type: services.msc
    3. Find: MySQL80
    4. Right-click → Start

  Problem: "Flask not running"
  Solution:
    Double-click: start_backend.bat

  Problem: "Port 5000 already in use"
  Solution:
    Double-click: stop_all.bat
    Then: start_all.bat

  Problem: "Everything broken!"
  Solution:
    1. Restart your computer
    2. Double-click: start_all.bat
